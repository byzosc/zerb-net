## 0. 已被否决的原型（`index.html`，别在它上面修补）
Z 放电 → 橙色波形起振 → 锁相 → 波形变成 o·s·c → 心跳。用户评价：「奇丑无比、太拉跨、既不符合审美动效也不优美、基本没有优点」。
我（Claude）的归因：**静态标本身不成立**——闪电 Z（面性、重、锐）+ Montserrat 800 的 osc（字体，另一套比例）+ 橙色细线波形，
三套视觉语言拼在一起；动效再精巧也只是在搬运一个拼凑的终态。概念（zosc = Z + oscillator，振荡器 = 万物起搏的脉冲）**没有被否**。

## 1. 用户给的参考（clip id：2etwe06e75 / sg83cyprr5 / 8eewpshdr8，宿主机 /data/Services/clip/files/<id>.png）
- 2×2 monogram：Z 的两横即 O/C 的弧，一个符号同时是 Z 与 O·C；细几何无衬线字标，橙色至多一个点
- 2×3 堆叠：ZO / SC 两行成方块，四字母共用圆角几何
- 单行字标：ZOSC 一根等粗线，O 圆角矩形、S 台阶、C 开口，Z 是唯一斜线
**共性：单线、等粗、几何、一个橙点以内、Z 是唯一锐角（与弧形成对比但材质相同）。整个 zosc 是一个物件。**

## 2. 硬约束
- 名字小写 `zosc` 为正；字标大写 ZOSC 可作为标志专用写法（参考里全是大写），需说明理由
- 颜色：黑 #050505 / 纸白 #f4f3ef / 橙 #e7503a 只能作为单点强调；favicon 必须在 16px 成立且黑白
- 不得与 MakerLion（橙 + 黑 + 闪电 Z）混淆。**待用户拍板**：zosc 是否放弃闪电 Z 改用全新几何 Z（Claude 倾向放弃）
- 动效只允许「一个动作」：一笔画出 / 一次展开 / 一次旋转，不允许多段式分镜；时长 ≤ 1.2s；落位优先页头 logo hover 与页面切换，Hero 不动
- 最终交付必须是：静态 SVG（标 + 字标 + 组合）、16/32px 黑白 favicon 版本、一段 ≤1.2s 的签名动效、在深色站点上的真实截图

## 3. Claude 提出的三个方向（请 Codex 逐个批评，并至少提一个我没想到的）
**A. 一笔线 ZOSC（参考图三的路线）**：整词一根等粗线，Z 的斜线是唯一直线。动效 = 这根线从 Z 的左上角**一笔画到 C 的开口**（stroke-dashoffset），
0.9s，像示波器扫描。振荡器意象靠「一根连续信号线」表达，不画波。
**B. Z∘ monogram（参考图一 #01 的路线）**：Z 的上下两横弯成 O/C 的弧，中间斜线；单独成标，可做 favicon。字标用细几何无衬线 ZOSC。
动效 = 斜线先落、两道弧**各转 90° 合上**，0.6s。
**C. ZO/SC 方块（参考图二 #06）**：2×2 字母块，O 的圆心一个橙点（= 示波器光点 / 心跳）。动效 = 四格依次亮起 0.4s，橙点最后出现。
最适合社交头像与印刷，最不适合页头。

我的倾向：**A 为主标（字标即标志），B 作为 favicon/头像的缩写形式**，两者共用同一笔画粗细与圆角半径，保证"一体"。
