# zosc 签名动效原型：Z 放电 → 起振 → 锁相 → 落成 o·s·c → 心跳

2026-10-08 · lab 原型，**不进站点**（`app/` 里没有任何引用）。零构建、单文件，浏览器直接打开 `index.html` 即可（也可以 `python3 -m http.server` 起一个静态服务）。

- `?v=orange`（默认）/ `?v=white`：osc 落定后的颜色
- `?t=1810`：冻结在第 1810 ms（录帧、截图用）
- `?debug=1`：在终态字母上叠一层浏览器真排的 Montserrat 800 "osc" 描边，用来证明烘进页面的路径和字体一致
- 右下角 Replay / Orange / White；系统开了「减少动态效果」时直接显示终态，没有心跳

## 概念

`zosc` = **Z + osc(oscillator)**。Z 是出品人（闪电 Z 标：三笔直线、锐角＝放电），osc 是振荡器（合成器的声源、芯片的晶振），也是动效的原语（缓动、弹簧、正弦）。o、s、c 全是曲线，能从一条连续波形里长出来。记忆点：**波形变成字**。

## 因果链（时序可调，因果不变）

1. **Z 放电**：按笔顺 上横 → 斜 → 下横 劈出来；斜笔落地那一帧全白 + 光晕；电流沿下横跑到末端（斜切角的右上角）。
2. **起振**：那个末端就是振荡器的输出口——一条橙色细线从这里甩出去，带着乱的高频抖动，幅度由小到大；光点骑在线头上。
3. **锁相**：起振期间波形一直向右走，到 900 ms 恰好停在整周期上，于是波段起点成了一个"节点"（钉住）。之后噪声消失、波形以这个节点为轴被拉长：频率下降，一个周期一个周期从右端滑出去、一次比一次慢，最后只剩**恰好两个周期**；幅度回弹一次后落定（弹簧）。锁定那一刻光晕亮一下。
4. **落字**（从左到右依次，全部是路径插值，没有任何淡入淡出换图）：
   - **o** = 引线 + 第一个波峰：两端绕 o 的圆心往下摆，在底部"咔"地合上成环
   - **s** = 下一个完整周期（先谷后峰）：绕自身中心顺时针立起 90°，同时由正弦变形成 Montserrat 的 s
   - **c** = 最后一个波谷：绕碗心顺时针滚 90°，继续卷到 c 的开口为止停住（带一点弹簧过冲）
   - 每个字都是先走完字的路径，再长出 Montserrat 800 的字重
5. **心跳**：每 2.7 s，o 的字怀里亮一个示波器光点、扩一圈，极轻。

## 时序表（ms）

| 时间 | 发生什么 | 怎么做 |
|---|---|---|
| 0–85 | Z 上横从左往右擦出 | SVG mask：粗的平头描边 + dashoffset |
| 85–190 | 斜笔向左下劈下 | 同上，ease-in（越劈越快） |
| 190 | 闪光 | Z 填充全白 33 ms + 同样被遮罩的模糊副本衰减 |
| 190–335 | 下横跑到末端 | 同上；斜切的尖角最后才露出来 |
| 345–820 | 细线甩到波段右端 | 折线 y(x,t)，每 2 个字体单位一个点；线头＝光点 |
| 345–900 | 抖动，幅度 ×0.05 → ×1.15 | value noise + 两个正弦，每 30 ms 重新取种子；波形右行，900 时停在整周期 |
| 900–1400 | 锁相 | 以波段起点为节点，周期数 9 → 2（ease-out）；1300 前噪声归零；幅度 240 ms 周期回弹，1400 精确落定 |
| 1420 | 锁定提示 | 光晕和线条亮一下（高斯 60 ms） |
| 1400–1540 | 干净正弦停留 | 静止，干净正弦可读约 300 ms |
| 1540–1960 | o 合环 | 161 根"横档"的极坐标插值；约 1896 合上，之后只长字重；结束换成字体原轮廓 |
| 1620–2040 | s 立起 | 刚体旋转 + 旋转坐标系内插值，6° 弹簧过冲 |
| 1700–2120 | c 滚动停住 | 极坐标插值 + 同样的弹簧 |
| 2550 起每 2700 | 心跳 | 光点 + 一圈，900 ms |

## 关键做法

- **整页是 `render(t)` 一个纯函数**，不用 GSAP / flubber / CDN，所以任意时刻都能精确 seek，录出来每次一样；JS 每帧 < 0.5 ms。
- **全部在一个坐标系里**：Montserrat 字体单位（1000/em），y 向下，基线 y=0，o 的原点 x=0。Z 标高度 = 大写字高 700，Z 到 o 的间距 70，osc 不加字距（Montserrat 在 o-s、s-c 之间没有 kerning）。整组宽度 = 1600 画布的 55%。
- **字形**：`build-glyphs.py` 用 fontTools 把可变字体实例化到 wght 800，取出 o/s/c 轮廓，给每个字配 161 根"横档"（笔画两侧一一对应的点对）。o、c 用从中心发出的等角射线取点（两者都对中心星形，c 的两个切口恰好是径向的），s 不是星形，就在两个切口处把轮廓切成两条边，用动态时间规整（DTW）配对。结果烘进 `index.html` 的数据块；页面运行不依赖这个脚本。
- **波形是按字算出来的，不是反过来**：波长 = o 中心到 c 碗心距离的 2/3（811.8 单位），振幅 = o 中线半径（204），轴线 = o 的中心高度。所以一个波峰本来就是 o 的上半圈，最后一个波谷本来就是 c 的下半圈。
- **波形极性由 s 决定**：只有"先往下"的那个周期立起来才是 S（另一种极性会得到镜像的 S，旋转改变不了镜像）。所以顺序只能是 峰(o)、谷+峰(s)、谷(c)，引线也必须向上离开 Z。
- **核对**：`?debug=1` 叠了浏览器自己排的 Montserrat 800，和烘进去的路径完全重合。

- `record.mjs` 用 Node 自带的 WebSocket 走 Chrome DevTools Protocol：自己起一个 HTTP 服务（端口随机）给页面，逐帧 `osc.seek(t)` → 等两次 rAF → 截图。
- GIF：直接按 1200×675 渲染，帧距 30 ms + GIF 延时 3 厘秒 = 恰好实时（GIF 延时只能是整厘秒，1/30 s 表示不出来）；t = −240…6300 共 219 帧（含两次心跳）。ImageMagick 先从一组代表帧取 96 色公共调色板，再不抖动地映射 + `OptimizePlus`，约 0.4 MB。
- 也可以不用 CDP，按「一帧一次无头截图」：页面支持 `?t=`，`chromium --headless --screenshot=… --window-size=1600,900 "http://127.0.0.1:端口/index.html?t=1810"`。
- 坑：这台机器的 chromium 是 snap，读不了 `/tmp`、隐藏目录、`/data`，所以页面必须走 HTTP，浏览器 profile 放 `~/render-tmp/osc/`，图片由 node 写盘。ImageMagick 的像素缓存超过 1 GiB 会落盘，`MAGICK_TMPDIR` 指到 `/data/Projects/zerb-net/.render-tmp/osc-magick`。录完删掉 `~/render-tmp/osc/` 和那个 magick 目录即可。
- 坑：起临时静态服务别用固定端口、收尾别用 `pkill -f`——2026-10-08 用固定端口 4391 时撞上了另一个会话的服务，截到的是别人的页面。

## 已知取舍

- 抖动每 30 ms 完全随机一次：看起来是电噪声，但在慢屏上可能像闪烁。
- s 立起来的同时必须缩短（一个周期 812 单位长，s 只有约 470 高），这是唯一一处"同一段弧"被明显缩放、而不只是弯折。
- Z 末端到第一个波峰的那段引线并进了 o（o 的左腿从 Z 那边摆过来），所以 o 是唯一一个由"多于一段弧"做成的字。
- 白色版：每个字落定时由橙变白，中间约 4 帧是浅鲑鱼色。
- 唯二的离散切换是"折线 → 三条带"和"带 → 字体原轮廓"，两处都发生在几何已经重合的那一帧。
