MotionRules is a small suite of motion design tools built around one idea: write your motion rules down once, then actually use them. Everything runs on one shared file, motion-tokens.json — named easing curves, duration steps and stagger — so the spec, the After Effects work and the developer handoff all agree.

Three tools, one spec

  • MotionSpec — define. A spec editor for design leads: drag cubic-bezier curves with a live preview (overshoot allowed), name the standard durations and stagger steps, set the audit tolerance, then export, share or publish motion-tokens.json.
  • MotionPilot — build. An After Effects panel that turns a sentence into keyframes, with curves, durations and stagger locked to the same spec, so the output is compliant by construction.
  • MotionSheet — hand off and audit. Upload a Bodymovin/Lottie JSON to play it back, click through a layer timeline, generate a merged-cell handoff table and run a spec audit that flags violations. The file is read in your browser and never uploaded to a server.

It serves the whole chain: the lead who owns the motion language, the designers animating in After Effects, and the developers who implement the result — they get delays, durations and curves as exact values instead of guesses.

The site also publishes the official Motion Spec for app and glasses interfaces, and a guide to how the three tools fit together.
